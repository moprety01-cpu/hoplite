# Экспонат I. Глобус, который печатает сам себя

`globe.js` — это рисунок Земли и одновременно программа на JavaScript. Запустите её:

```sh
node exhibits/1-globe/globe.js
```

Она напечатает **новую программу**: ту же Землю, повёрнутую на 15° (на один час). Напечатанное снова запускается и печатает следующий час. Через 24 запуска выходит файл, совпадающий с исходным **байт в байт**.

```sh
node exhibits/1-globe/spin.mjs    # Земля вертится в терминале; каждый кадр — вывод предыдущего
node exhibits/1-globe/verify.mjs  # 24 настоящих запуска node и сравнение с исходником
```

## Как это устроено

Весь файл — одно выражение:

```js
eval(c=`  …Земля из кода…  `.replace(/[\s█]/g,''))
```

1. Между обратными кавычками лежит код, разложенный по клеткам океана. Перед запуском из него выбрасываются пробелы, переводы строк и блоки суши `█`. Остаток склеивается в обычную однострочную программу, кладётся в переменную `c` и выполняется. Так программа знает собственный текст: это квайн.
2. Программа распаковывает карту мира. Это 120×60 клеток Natural Earth 1:50m, сжатые кодированием длин серий в строку `M` из 506 символов. Затем она строит ортографическую проекцию шара 88×40 символов: камера на 20° выше экватора, центральный меридиан сдвигается на 15° за запуск.
3. Клетки суши заливаются `█`. Клетки океана по порядку чтения заполняются её собственным кодом (`c`), в котором номер часа `A` увеличен на единицу.
4. Кода (1351 символ) меньше, чем океана (от 1410 до 2331 клетки, в зависимости от часа). Поэтому хвост океана становится комментарием `/*…*/`. В нём сначала плавает фраза «И·всё‑таки·она·вертится», а дальше повторяется код. При следующем запуске этот хвост отбрасывается.
5. Всё, что программа печатает, зависит только от часа и от её собственного кода. Час идёт по кругу `(A+1)%24`, поэтому через 24 шага получается тот же файл. Каждый из 24 кадров — отдельная работающая программа, и все они разные.

Ограничения, которые соблюдает код: в нём нет ни одного пробела, обратной кавычки, обратной косой черты, `${`, `/*` и `*/`. Символ `█` в коде тоже не встречается, он выводится через `String.fromCharCode(9608)`.
