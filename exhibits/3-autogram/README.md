# Экспонат III. Предложение, которое пересчитало себя

> В этом предложении ровно сорок две буквы «а», тридцать четыре буквы «б», сорок девять букв «в», одна буква «г», тридцать девять букв «д», двадцать одна буква «е», одна буква «ё», две буквы «ж», одна буква «з», одиннадцать букв «и», одна буква «й», тридцать шесть букв «к», две буквы «л», две буквы «м», девятнадцать букв «н», двадцать букв «о», шесть букв «п», пятнадцать букв «р», пять букв «с», тридцать пять букв «т», тридцать четыре буквы «у», одна буква «ф», одна буква «х», четырнадцать букв «ц», пять букв «ч», три буквы «ш», одна буква «щ», одна буква «ъ», четырнадцать букв «ы», двадцать две буквы «ь», две буквы «э», одна буква «ю» и девять букв «я».

Сосчитайте сами: это предложение называет, сколько раз в нём встречается каждая из 33 букв русского алфавита, и ни разу не ошибается. Всего в нём 450 букв. Такие предложения называются **автограммами**. Эта к тому же панграмма: в ней есть все буквы алфавита.

```sh
node exhibits/3-autogram/verify.mjs
```

## Почему это трудно

Каждое число в предложении само состоит из букв. Замените «сорок одна» на «сорок две», и изменится количество букв «о», «д», «н», «в», «е», «а». Тогда придётся менять и эти числа, а за ними другие. Нужно найти такую точку, в которой предложение описывает само себя: из 33 чисел, каждое из которых влияет на все остальные.

Поиск (`search.c`) устроен так. Для каждого числа заранее посчитано, сколько каких букв оно добавляет вместе со словом «буква/буквы/букв» и самой буквой в кавычках. Дальше идёт случайное блуждание: на каждом шаге берётся одно из расхождений между заявленным и настоящим и исправляется, а время от времени поиск начинается заново. Решение нашлось за 38 924 364 шага, примерно за 6 секунд на одном ядре (запуск `./search 0 1 40`). Ещё 1,3 миллиарда шагов не дали другого решения для этой формулировки. Похоже, оно единственное, но это не доказано.

Грамматика честная: числительные женского рода согласованы с «буквой» («одна буква», «две буквы», «пять букв»), а буква «ё» встречается только в «ё».
