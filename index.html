Экспонат I

Глобус, который печатает сам себя

JavaScript · 3 218 символов · поступил в коммите 0000001

загрузка…
00:00

Это не картинка, а программа. Запустите её — она напечатает новую программу: ту же Землю, повёрнутую на 15°, то есть на один час. Запустите напечатанное — получите следующий час. Через 24 запуска программа возвращается к самой себе байт в байт: сутки, записанные кодом.

Океаны здесь — это исходный код. Перед запуском программа выбрасывает пробелы и блоки суши, склеивает то, что осталось, и выполняет. Континенты — просто дыры в коде. Если кода не хватает на весь океан, остаток заполняется комментарием, а в волнах плавает фраза, которую приписывают Галилею: «И всё‑таки она вертится».

Каждый кадр выше — это вывод предыдущего кадра, который ваш браузер только что выполнил. Ничего не нарисовано заранее.

node exhibits/1-globe/globe.js            # напечатает следующий час
node exhibits/1-globe/spin.mjs            # крутит Землю в терминале

Экспонат II

Простое число, которое говорит

натуральное число · 625 цифр · поступил в коммите 0000002

Наведите на этот квадрат камеру телефона. QR-код скажет: «Я простое число». И это правда.

Прочитайте 625 цифр строка за строкой — получится одно число. Тёмные клетки — восьмёрки и девятки, светлые — единицы и семёрки. Число из одних «8» и «1» простым не было; простым его сделали ровно две заменённые цифры — и QR-код от этого не перестал читаться.

Ваш браузер ещё не начал проверку.

Выше ваш браузер проверяет число вероятностными тестами (Миллер — Рабин и строгий тест Люка, вместе — BPSW). Для полной строгости в музее лежит сертификат простоты ECPP — математическое доказательство, которое PARI/GP перепроверяет за доли секунды.

само число

node exhibits/2-prime/verify.mjs
gp -q exhibits/2-prime/verify_cert.gp     # строгое доказательство

Экспонат III

Предложение, которое пересчитало себя

русский язык · 450 букв · поступил в коммите 0000003

загрузка…

Наведите на любое «сколько букв» — и все эти буквы подсветятся.

Это предложение называет, сколько раз в нём встречается каждая из 33 букв русского алфавита, — и не ошибается ни разу. Такие предложения называют автограммами.

Трудность в том, что любое исправление ломает всё остальное: поменяешь «сорок одна» на «сорок две» — сразу изменится число букв «д», «в», «е», «о», «а»… Решение нашлось после 38,9 миллиона шагов случайного поиска, и, похоже, для этой формулировки оно единственное.

node exhibits/3-autogram/verify.mjs

Экспонат IV

Картинка, которая на самом деле архив

один файл · три формата · поступил в коммите 0000004

Это постер, файл kunstkamera.png. Он же — веб-страница: переименуйте его в .html и откройте. Он же — ZIP-архив со всем музеем: переименуйте в .zip и распакуйте.

Так можно, потому что каждый формат читает файл со своей стороны. PNG читают с начала и вежливо пропускают незнакомые фрагменты — в одном из них, по имени htMl, лежит страница. ZIP читают с конца — архив дописан после последнего байта картинки. А HTML прощает любой мусор вокруг себя.

что внутри архива
    unzip -l exhibits/4-chimera/kunstkamera.png
node exhibits/4-chimera/verify.mjs

    Экспонат V

    История, которой не может быть

    git · SHA-1 · поступил в коммите 0000005

    1. загружаю историю репозитория с GitHub…

    Посмотрите на номера коммитов этого репозитория: 0000000, 0000001, 0000002… Так не бывает. Номер коммита в git — это SHA-1 от его содержимого. Его нельзя выбрать, можно только угадать. Шанс, что хеш начнётся с семи нужных цифр, — один к 268 435 456.

    Каждый из этих коммитов — результат перебора сотен миллионов вариантов. Перебирались невидимые символы: в конце сообщения каждого коммита спрятаны 32 пробела и табуляции, и только одна их комбинация из нескольких миллиардов даёт нужный хеш. Выше они проявлены: · — пробел, → — табуляция.

    Попробуйте сами. Ваш браузер будет дописывать к вашему имени числа, пока SHA-1 не начнётся с нулей.

    git log --oneline
node exhibits/5-history/verify.mjs

    Проверить всё сразу

    git clone https://github.com/moprety01-cpu/hoplite.git kunstkamera
cd kunstkamera && node verify.mjs

    Кунсткамеру за один вечер собрал ИИ: перебором SHA-1, проекциями сфер, тестами простоты, случайным поиском по русским числительным и двумя форматами файлов, сшитыми в третий. Никаких зависимостей: всё, что здесь работает, лежит в репозитории.
